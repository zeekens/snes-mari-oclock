# Pack 3 2.3.0

15 scenes. Extract the complete ZIP and open `previews/index.html`. Click **Next minute** to preview minute actions. Requires sntl-2.2.0 or newer.

Scene paths are relative to `manifest.json`; `catalog_path` points to the online repository asset. All native frames use 80 ms cadence, matching the 40 ms display interval. Across all three packs, the 15 formerly 60 ms scenes now run 25% slower. See each preview's audit note for scene-specific changes.

Bubble Bobble is included in Pack 2. The separate Tide Pool built-in fix requires firmware sntl-2.2.1; packs alone cannot change built-in scenes. Hardware visual playback is not certified.
