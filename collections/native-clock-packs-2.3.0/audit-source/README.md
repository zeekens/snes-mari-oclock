# Retained audit authoring source

These files document the reviewed rendering and checks. They require the existing SNES-clock workbench, its historical renderer inputs, backup gallery and generated native baseline; they are not standalone scene builders. The published assets and offline archives can be verified and repackaged without that workbench using `device-firmware/tests/pack_release_test.py` and `device-firmware/scripts/native-packs/package_reviewed.py`.
